## 1\. BRAND OVERVIEW

LumenLogic is an intelligent B2B procurement platform built for the architectural lighting industry. It combines EU-subsidised AI technology with deep lighting domain expertise to automate quote generation, product matching, and project delivery for architectural lighting professionals.

### Brand Positioning

- **Mission:** Democratise professional lighting procurement through intelligent automation  
- **Tone:** Expert, trustworthy, precise, forward-thinking (not flashy)  
- **Audience:** Lighting designers, architects, procurement professionals, electrical contractors, construction firms across EU

### Core Values

- **Intelligence:** AI-powered, data-driven decision-making  
- **Transparency:** Clear pricing, open algorithms, no black boxes  
- **Expertise:** Rooted in 25+ years of lighting industry knowledge  
- **Efficiency:** Reduce procurement friction, accelerate project delivery  
- **Partnership:** Enable professionals, not replace them

## 2\. LOGO & IDENTITY MARK

### Primary Logo

**Format:** LumenLogic wordmark \+ layered translucent icon system  
**Style:** Clean, modern geometric sans-serif with optical depth layering

#### Logo Specifications

- **Wordmark:** "lumenlogic" in custom sans-serif (strict lowercase, tech-forward)  
- **Icon System:** Layered translucent geometric forms suggesting light transmission, depth, layers  
- **Geometry:** Circles/rings with opacity variations creating 3D illusion without actual 3D  
- **Primary Aesthetic:** Minimalist, professional, subtle technical sophistication

#### Logo Variations

1. **Full Horizontal (Wordmark \+ Icon)** — primary for web, applications, business docs  
2. **Icon Only** — favicon, app icon, small-space applications (minimum 24px)  
3. **Vertical Stacked** — constrained horizontal space  
4. **Monochrome (Black)** — print, restricted-colour environments  
5. **Monochrome (White)** — on dark backgrounds, inverse spaces  
6. **Outlined** — secondary, when layering/translucency can't render  
7. **Animated (Icon)** — subtle light-transmission animation (fade-in-out layers)

#### Logo Usage Rules

- **Minimum Size:** 24px (icon only), 48px (full logo)  
- **Clear Space:** Minimum 8px on all sides (icon), 12px around wordmark  
- **Layering:** Always maintain translucency/opacity in icon (never solid fills)  
- **Don't:**  
  - Add drop shadows, glows, or effects (layering does the work)  
  - Rotate or skew  
  - Mix colour versions randomly  
  - Scale disproportionately  
  - Combine with other company logos at equal prominence  
  - Rasterise unnecessarily (keep as vector SVG)

## 4\. TYPOGRAPHY

### Display Typeface: **Inter** (Variable)

**License:** Open-source SIL OFL  
**Weights Used:** 600 (Semibold), 700 (Bold)

#### Display Usage

- **Sizes:** 24px–96px  
- **Line Height:** 1.2 (compact, professional)  
- **Letter Spacing:** 0 (neutral), tight on 64px+  
- **Weight Hierarchy:**  
  - **600 (Semibold):** Section headings, feature titles (28–48px)  
  - **700 (Bold):** Hero headlines, major CTAs (64–96px)

#### Display Examples

- **Hero Copy** (64–96px): "Intelligent Lighting Procurement", "Quote in Seconds"  
- **Section Heads** (36–48px): "Platform Features", "Trusted by 300+ brands"  
- **Subheads** (24–32px): Feature descriptions, call-outs

### Body Typeface: **Inter** (Variable)

**License:** Open-source SIL OFL  
**Weights Used:** 400 (Regular), 500 (Medium), 600 (Semibold)

#### Body Usage

- **Sizes:** 13px–18px (UI/app), 14px–18px (marketing)  
- **Line Height:** 1.5–1.6 (generous for readability)  
- **Letter Spacing:** 0 (neutral)  
- **Weight Hierarchy:**  
  - **400 (Regular):** Body copy, descriptions, supporting text  
  - **500 (Medium):** Labels, button text, UI emphasis  
  - **600 (Semibold):** Strong emphasis, data labels, captions

#### Body Examples

- **Marketing Body:** 16px Inter 400, line-height 1.6, colour \#3F4A5C  
- **UI Labels:** 14px Inter 500, line-height 1.4, colour \#1A1A1A  
- **Button Text:** 15px Inter 600, sentence case, no additional letter-spacing

### Monospace (Code/API)

- **Font:** SF Mono or JetBrains Mono (tech audience)  
- **Usage:** API documentation, code samples, data fields, technical specs  
- **Size:** 12px–14px, line-height 1.5  
- **Colour:** \#3F4A5C or \#1A1A1A on light backgrounds

### Font Pairing Summary

Display:  Inter (600, 700\) — clean, authoritative

Body:     Inter (400, 500, 600\) — open, scannable

Code:     SF Mono / JetBrains Mono — technical precision

Strategy: Monotype system (Inter across all) for cohesion

## 6\. VISUAL ELEMENTS & IMAGERY

### Photography Style

**Direction:** Professional, authentic, industry-focused (architectural, technical, human)

#### Do's

- Architects/lighting designers at work (offices, on-site, meetings)  
- Project renders and technical visualisations  
- Product UI screenshots (real examples from platform)  
- Real lighting installations, project outcomes  
- Diverse professionals, genuine expressions  
- B2B context (not consumer marketing)

#### Don'ts

- Stock photo look (staged, artificial)  
- Bright, playful lifestyle imagery  
- People in non-professional settings  
- Isolated product shots (context matters)  
- Oversaturated colours  
- Corporate clichés (blank stares, forced smiles)

### Illustrations & Graphics

#### Illustration Style

- **Aesthetic:** Minimal, technical, subtle  
- **Palette:** Navy, professional blue, teal (accent only)  
- **Complexity:** Medium-low (clean lines, purposeful shapes)  
- **Use Cases:** Process diagrams, feature explanations, data flow, icons  
- **Not:** Playful, animated characters (keep it professional)

#### Graphic Elements

- **Lines & Geometry:** Clean, precise, 1–2px stroke weight  
- **Icons:** 24px base, 1.5px stroke, minimal style (technical focus)  
- **Accent Shapes:** Subtle geometric forms (circles, rectangles, nodes) using opacity/translucency  
- **Data Viz:** Line charts, bar charts, heat maps following technical palette; minimal decorative elements

### Diagrams & Process Flows

- **Style:** Technical, wireframe-like, clear hierarchy  
- **Colour:** Monochrome (navy/slate) with teal highlights for key flows  
- **Connections:** Clean lines, directional arrows, minimal ornamentation  
- **Labels:** Clear, concise, technical terminology accepted

### Video & Motion

- **Duration:** 2–4 seconds (feature demos), 0.2–0.4s (UI transitions)  
- **Easing:** Ease-in-out, smooth curves (no bouncy effects)  
- **Use:** Product walkthroughs, data transformation, system animations  
- **Accessibility:** Always provide static alternative, respect prefers-reduced-motion

## 12\. ANIMATION & MOTION

### Micro-interactions

- **Hover Effects:** 150ms ease-out duration  
- **Click/Tap Feedback:** 100ms scale (0.96–1.0)  
- **Form Validation:** 200ms fade-in for messages  
- **Loading States:** Pulse animation or spinner (12px, navy, 1.5s)

### Entrance/Exit Animations

Page Load:     Fade-in 300ms ease-out

Modal Open:    Scale (0.95 → 1.0) \+ fade-in, 200ms

Modal Close:   Scale (1.0 → 0.95) \+ fade-out, 150ms ease-in

Slide Panel:   Translate X \+ fade-in, 250ms ease-out

### Easing Curves

Entrance:      ease-out (cubic-bezier(0, 0, 0.2, 1))

Exit:          ease-in (cubic-bezier(0.4, 0, 1, 1))

Interaction:   ease-in-out (cubic-bezier(0.4, 0, 0.2, 1))

### Avoid

- Animations longer than 400ms (feels sluggish)  
- Multiple simultaneous animations on same element  
- Animations disabled if user has prefers-reduced-motion set  
- Gratuitous movement (let interactions have purpose)

## 15\. USAGE GUIDELINES & BEST PRACTICES

### Logo Usage

✅ **Do Use**

- SVG format whenever possible (maintains layering/translucency)  
- Monochrome black on white/light backgrounds (primary)  
- Monochrome white on dark navy backgrounds  
- Minimum 24px (icon), 48px (full logo with wordmark)  
- Adequate clear space (8px minimum)

❌ **Don't**

- Add drop shadows, glows, or reflective effects (defeats layering aesthetic)  
- Rotate, skew, or distort  
- Rasterise (always keep vector)  
- Combine with other logos at equal prominence  
- Change opacity of layers randomly  
- Use outdated versions

### Colour Usage

✅ **Do Use**

- Navy (\#1A1F3A) for primary CTAs and accent elements  
- Professional blue (\#2D5A8C) for secondary CTAs and links  
- Teal (\#1BA89A) for success states, highlights, data emphasis  
- White on navy for strong contrast  
- Translucent layers in icon (opacity system)

❌ **Don't**

- Create gradients (not part of LumenLogic brand)  
- Use secondary colours in primary CTAs  
- Neglect WCAG 4.5:1 contrast ratio  
- Apply colour purely decoratively  
- Mix with other brand colour systems

### Typography

✅ **Do Use**

- Inter exclusively (display \+ body)  
- Weight hierarchy: 600/700 display, 400/500/600 body  
- Line-height 1.2 display, 1.5–1.6 body  
- 13px minimum for UI, 14px for marketing  
- Professional, straightforward writing tone

❌ **Don't**

- Mix Inter with other typefaces  
- Use decorative fonts  
- Set body smaller than 13px  
- Ignore line-height recommendations  
- Use overly casual or playful copy

### Spacing

✅ **Do Use**

- 8px grid system consistently  
- 24–32px section gutters  
- 20px card padding minimum  
- Breathing room around interactive elements  
- Generous line-height for readability

❌ **Don't**

- Random spacing values  
- Cramped layouts  
- Inconsistent gutters  
- Orphaned text (hanging near edges)

### Component Design

✅ **Do Use**

- 6–8px border-radius (professional, not rounded)  
- Subtle shadows (0 2px 8px max)  
- 150–200ms transition durations  
- Clear focus states on all interactive elements  
- Logical tab order

❌ **Don't**

- Extreme rounding (pill buttons lose professional feel)  
- Heavy shadows (looks less refined)  
- Instant transitions (jarring)  
- Invisible focus states  
- Keyboard navigation issues

## 17\. BRAND VOICE & MESSAGING

### Tone Attributes

- **Expert:** Knowledgeable, confident in domain  
- **Trustworthy:** Transparent, honest, no hype  
- **Efficient:** Direct, purposeful, respects user time  
- **Professional:** Serious about the work, not corporate-stiff  
- **Empowering:** Enable professionals, highlight their expertise

### Writing Principles

- **Active Voice:** "Automate your quotes" not "Quotes can be automated"  
- **Clear Language:** Avoid jargon unless audience-specific  
- **Short Sentences:** 15–20 words average  
- **Benefit-First:** Lead with outcomes, not features  
- **Concrete Examples:** Use real lighting scenarios

### Writing Examples

✅ "Quote complex projects in seconds"  
✅ "Match the right products to your design, every time"  
✅ "Built by lighting professionals, for lighting professionals"

❌ "Optimise your procurement workflow leveraging AI-driven intelligent systems"  
❌ "Revolutionary technology disrupting traditional lighting distribution"

### Messaging Hierarchy

1. **Primary:** Efficiency, accuracy, time-saving  
2. **Secondary:** Expertise, trust, professional control  
3. **Tertiary:** Technology (mention AI/ML, don't lead with it)

## 19\. COMMON MISTAKES TO AVOID

1. **Destroying Logo Layering:** Don't flatten or apply solid fills to icon  
2. **Overusing Shadows:** Subtle is professional; dramatic shadows look cheap  
3. **Random Padding:** Breaks the 8px grid, creates visual inconsistency  
4. **Low Contrast Text:** Always verify 4.5:1 WCAG ratio  
5. **Skipping Focus States:** Users navigating via keyboard will get lost  
6. **Mixing Typefaces:** Inter everywhere; don't add Georgia or Helvetica  
7. **Forgetting Mobile:** Design desktop-first, but test mobile layouts thoroughly  
8. **Ignoring Accessibility:** Colour-only states, missing labels, broken forms exclude users  
9. **Overanimating:** Not every interaction needs motion; reserve animation for meaningful feedback  
10. **Treating B2B Like Consumer:** Avoid playful, trendy design; stick to professional, timeless  
11. **Using Outdated Brand Assets:** Always use current logo version  
12. **Adding Decorative Elements:** Every element should serve a purpose

## QUICK REFERENCE CHEAT SHEET

PRIMARY COLORS

• Navy (Primary): \#1A1F3A (RGB: 26, 31, 58\)

• Professional Blue (Secondary): \#2D5A8C (RGB: 45, 90, 140\)

• Teal (Accent): \#1BA89A (RGB: 27, 168, 154\)

• Slate Grey (Text): \#3F4A5C (RGB: 63, 74, 92\)

• Light Neutral: \#F0F2F5 (RGB: 240, 242, 245\)

FONTS

• Display: Inter (600, 700\) — sizes 24–96px

• Body: Inter (400, 500, 600\) — sizes 13–18px

• Code: SF Mono / JetBrains Mono

SPACING (8px Grid)

• Buttons: 10px V × 16px H (44px min height)

• Cards: 20px padding

• Sections: 32px gutters (desktop), 24px (tablet), 16px (mobile)

• Inputs: 12px V × 14px H

BUTTONS

• Primary: Navy bg, white text, 6px border-radius, 44px height

• Secondary: Transparent, blue border 2px, 44px height

• Tertiary: Ghost (no border, blue text, 8px padding)

COMPONENTS

• Cards: 8px border-radius, 1px border \#E5E9F0, shadow 0 2px 8px

• Inputs: \#F5F7FA bg, \#D0D6E0 border, focus \#2D5A8C

• Focus Ring: 2px solid \#2D5A8C, 2px offset

CONTRAST (WCAG)

• Text: Minimum 4.5:1 ratio

• Large Text: Minimum 3:1 ratio

• Always test foreground vs background

RESPONSIVE

• Mobile: 320–768px (single column, full-width)

• Tablet: 768–1024px (2–3 columns)

• Desktop: 1024–1280px (optimal B2B)
